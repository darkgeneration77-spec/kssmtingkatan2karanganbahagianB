Phase 1 · Module 05

Surat

格式作文最容易让学生把注意力全放在“地址摆哪里”，然后正文离题。这里先把 Surat 当成外壳：先识别正式或非正式，再把 Pengalaman 或 Fakta/Pendapat 内容装进去。

Surat 先分两类

Surat Kiriman Tidak Rasmi

写给朋友、亲戚、家人。语言可以自然亲切，但格式仍要完整。

Alamat pengirim → Tarikh → Kata menghadap surat → Isi → Penutup → Tandatangan / Nama

Surat Kiriman Rasmi

写给校方、机构、单位负责人。语气正式，目的必须清楚。

Alamat pengirim → Alamat penerima → Tarikh → Tuan/Puan → Tajuk → Isi bernombor/perenggan → Penutup rasmi → Tandatangan/Nama

视觉记忆：先包格式，再放内容

ALAMAT谁写、写给谁
TARIKH日期
PEMBUKA称呼 / 目的
ISI真正作文内容
PENUTUP结束 + 署名

不正式信件例题

Tulis sepucuk surat kepada rakan anda untuk menceritakan pengalaman menyertai Hari Sukan sekolah.

核心内容仍是 Pengalaman。Surat 只是外壳。

正式信件例题

Tulis sepucuk surat kepada pihak sekolah untuk mencadangkan langkah meningkatkan kebersihan sekolah.

核心内容仍是 Fakta / Pendapat。不要因为有格式就忘记题目真正要你回答什么。

最常见失分点

1. 正式与不正式格式混用。

2. 写完地址和称呼后，正文却没有回答题目。

3. 结尾语气不合对象。

4. 署名、日期、标题位置完全凭感觉。

小练习：题目要求写给朋友，分享一次学校活动经历。最合适的是哪一种？
