学生学习中心

审题 → 判断 Kehendak → 找内容 → 写段落 → 完整作文 → 模拟 → 检查 → 订正

先学会“题目要什么”，再追求漂亮语言。方向错了以后，句子越华丽，只是更有礼貌地离题。

0｜看到题目先判断

Tema → Kata Tugas → Jenis → Kehendak → 合适写作结构。

1｜Kata Tugas 题型转换

Cara、Faedah、Kepentingan、Punca、Kesan、Peranan、Pendapat、Pengalaman。

2｜专业开头与结尾

按 Kehendak 调整 Pendahuluan；Penutup 负责收束，不增加新 Isi。

3｜Fakta / Pendapat 高分写作

DSKP 核心：Topik → Huraian → Contoh → Penegasan；Kesan 作为教学扩展桥梁。

4｜Pengalaman / Cerita

Latar → Perkembangan → Cabaran/Detik penting → Penyelesaian → Perasaan/Pengajaran。

5｜12 Tema 高分句段

Tema 提供内容材料，Kata Tugas 决定答案方向。

6｜5-Level 写作训练阶梯

认题型 → 选 Isi → 补发展链 → 独立段落 → 完整作文。

7｜Karangan Berformat

格式是外壳，Kehendak 与 Isi 才是内容核心。

专业范文 Set 1｜Kebersihan

Pengalaman、Langkah、Laporan。

专业范文 Set 2｜Kesihatan

Pengalaman、Faedah、Syarahan Cara。

专业范文 Set 3｜Teknologi

Pengalaman、Kebaikan、Surat Tidak Rasmi。

专业范文 Set 4｜Sukan

Pengalaman、Kepentingan、Laporan。

专业范文 Set 5｜Alam Sekitar

Pengalaman、Langkah、Ucapan Kepentingan。

专业范文 Set 6｜Perpaduan

Pengalaman、Cara Memupuk、Rencana Kepentingan。

6 Sets 专业范文总入口

只保留经过审核的参考版本，不放重复旧范文。

8｜UASA Simulation Mode

三选一、计时、独立作答，再进入教师诊断。

9｜6 Set 模拟题

不同 Tema 的实战训练。

10｜交卷检查

Kehendak → Struktur/Format → Isi → Bahasa，按风险顺序检查。
