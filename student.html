学生学习中心

审题 → 判断 Kehendak → 找内容 → 句子 → 段落 → 完整作文 → 模拟 → 检查

0｜看到题目先判断

Tema → Kata Tugas → Jenis → Kehendak → Engine。

1｜Kata Tugas 题型转换

12 Tema × Cara / Faedah / Kepentingan / Pengalaman。

2｜高分开头与结尾

Pendahuluan 与 Penutup 的可迁移结构。

3｜Fakta 高分写作

Topik → Huraian → Contoh → Kesan → Penegasan。

4｜Pengalaman / Cerita

Setting → Problem → Climax → Resolution → Reflection。

5｜12 Tema 高分句段

关键词 → 可写句 → 高分完整段。

6｜5-Level 写作训练阶梯

认题型 → 选 Isi → 补发展链 → 独立段落 → 完整作文。

7｜Karangan Berformat

格式视觉速查。

专业范文 Set 2｜Kesihatan

已完成内容专业审核：Pengalaman、Faedah、Syarahan Cara。

8｜UASA Simulation Mode

三选一、计时、独立作答、完成后分析。

完成作文后逐项检查。
