学生学习中心

审题 → 找内容 → 句子 → 段落 → 完整作文 → 模拟 → 检查

0｜看到题目先判断

Tema → Kata Tugas → Jenis → Kehendak → Engine。

1｜Fakta 高分写作

Pendahuluan、Ayat Topik、Huraian、Contoh、Kesan、Penegasan、Penutup。

2｜Pengalaman / Cerita 高分

Setting → Action → Problem → Climax → Resolution → Reflection。

3｜12 Tema 高分句段银行

关键词 → 可写句 → 高分完整段。不是只有 Isi 名称。

4｜12 Tema 完整 Isi Bank

Huraian、Contoh、Kesan 与题型转换。

5｜Karangan Berformat

Surat、Laporan、Ucapan、Rencana、Berita、Catatan。

6｜三级练习

Level 1 判断 → Level 2 组织 → Level 3 输出。

7｜UASA Simulation Mode

三选一、计时、独立作答、完成后分析。

8｜6 Set 模拟题

不同 Tema 的 Bahagian B 实战。

9｜交卷检查

完成作文后逐项检查。
