Diagnosis → Remedial｜作文诊断与补救

诊断不是写一句“Bahasa lemah”然后把问题交还给学生。必须把症状对应到下一项可执行训练。

使用方式：一次只抓 1–2 个主要弱点。先补最影响切题与表达的能力，再进入全文练习。

A｜Kehendak Soalan 错

症状
题目问 faedah，学生写 cara；问 pengalaman，却写成说明文；内容相关但方向错误。
补救
先做 Question Engine，再到 Kata Tugas 转换，训练 Cara / Faedah / Kepentingan / Punca / Kesan / Peranan / Pengalaman 的区别。

B｜有 Isi，但不会展开

症状
一段只有一句 Isi，再跟一句很空的说明；或 Huraian 只是换词重复 Ayat Topik。
补救
进入 Training Ladder Level 3–4。先练 Ayat Topik → Huraian → Contoh → Penegasan；需要时加入 Kesan 作为发展桥梁。

C｜想不到 Isi

症状
学生会写句子，但看到题目脑袋空白，或三个 Isi 实际上是同一点重复改写。
补救
使用 12 Tema 高分句段银行建立内容库存，再回到 Kata Tugas 转换把同一 Tema 改写成不同答题方向。

D｜Pengalaman / Cerita 流水账

症状
整篇只有 Kemudian / Selepas itu / Akhirnya，事件没有变化，结尾只有“saya sangat gembira”。
补救
使用 Narrative Engine：Latar → Perkembangan → Cabaran/Detik penting → Penyelesaian → Perasaan/Pengajaran。不是每篇都要硬造严重事故。

E｜开头/结尾背得漂亮，但不切题

症状
万能开头很长，真正 Tema 到第三四句才出现；结尾突然加入新 Isi。
补救
使用 Pendahuluan & Penutup，固定检查：Tema → Latar → Fokus；Rumusan → Tindakan/Cadangan → Harapan。

F｜Berformat 不稳定

症状
知道内容但漏标题、sapaan、身份、署名等文体外壳，或格式完整但正文没有回应 Kehendak。
补救
先到 Format Lab确认文体外壳，再回到 Question Engine 检查内容要求。格式是外壳，Kehendak 才是核心。

G｜Bahasa 错误多

症状
句子过长、结构混乱、连接词机械重复、ejaan / tanda baca / nahu 错误频繁。
补救
先把句子缩短，确保每句 gramatis，再逐步加入句式变化。一次集中修改一种错误，最后用 Checklist编辑。

H｜全文看似完整，但分数一直上不去

症状
有开头、有三点、有结尾，但内容浅、例子泛、段落发展重复，语言也长期停在同一层次。
补救
进入 四维诊断找最低维度，再完成 Before / After 订正。只重写全文但不诊断，通常只是再次复印同一个问题。

教师快速分流

不会审题 → Question Engine / Task Transform
没有 Isi → Tema Bank
不会展开 → Training Ladder 3–4
不会叙事 → Narrative Engine
格式错误 → Format Lab
语言错误 → Checklist + 针对性改错
全文不稳定 → Simulation → Scoring → Correction → Re-assessment
