Diagnosis → Remedial｜作文诊断与补救

不要只写“Isi tidak cukup”“Bahasa lemah”。那只是把问题重新命名一次，并没有治疗任何东西。

A｜Kehendak Soalan

症状
题目问 faedah，学生一直写 cara；内容看似相关但方向错。
补救
回到 Kata Tugas 题型转换，连续做“怎样做 / 有什么好处 / 为什么重要”分类。

B｜Isi 太短

症状
一段只有：Kita hendaklah bersenam. Hal ini baik untuk kesihatan.
补救
训练 Topik → Huraian → Contoh → Kesan → Penegasan。先用 Level 3，不要直接逼学生写全文。

C｜没有内容

症状
会写句子，但想不到 Isi。
补救
使用 12 Tema 高分句段银行：先记关键词，再口头说可写句，最后写段。

D｜Pengalaman 流水账

症状
Kemudian... Selepas itu... Kemudian... 最后活动结束，读者也差不多结束了。
补救
使用 Narrative Engine，强制加入 Problem、Climax、Reaction、Reflection。

E｜开头很华丽但不入题

症状
背万能开头，写了一大段还不知道题目是什么。
补救
使用 开头结尾银行，要求最后一句必须锁定 Kehendak。

F｜Bahasa 错误多

症状
句子过长、主谓关系乱、连接词机械重复、ejaan/tanda baca 频繁出错。
补救
先把句子缩短并确保 gramatis，再逐步加入连接和修饰。每次只改一种错误，最后使用 Checklist 编辑。

教师快速分流

不会审题 → Question Engine / Task Transform
没有 Isi → Tema Bank
不会展开 → Training Ladder Level 3–4
不会叙事 → Narrative Engine
全文不稳定 → Level 5 + UASA Mode + Checklist
