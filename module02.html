Pengalaman｜经历文

目标不是背一篇 Hari Sukan，而是掌握一条任何经历都能套用的事件时间线。题目一换，活动换掉，结构不换。

开头公式

Bila + Di mana + Aktiviti + Siapa

例：

Pada hari Sabtu yang lalu, sekolah saya telah mengadakan aktiviti gotong-royong. Saya dan rakan-rakan hadir lebih awal untuk mengambil bahagian dalam aktiviti tersebut.

结尾公式

Perasaan + Pengajaran + Harapan

例：

Saya berasa sangat gembira kerana dapat bekerjasama dengan rakan-rakan. Pengalaman ini mengajar saya bahawa semangat kerjasama amat penting. Saya berharap aktiviti seperti ini akan diadakan lagi.

中间怎样发展，才不会像流水账

  1. Sebelum：交代准备、集合、老师说明、分组。
  2. Semasa：写清楚你做了什么，不要只列活动名称。
  3. Kemuncak：一定放一个最突出事件，例如突然下雨、队友受伤、比赛逆转、发现遗失物。
  4. Selepas：交代活动怎样结束、结果如何。

最常见离题错误

错误：写成 Fakta

题目要你写经历，学生却写：Gotong-royong mempunyai banyak faedah...

这不是“我经历了什么”。

正确：写事件

写时间、地点、人物、动作、事件发展、感受。

Pengalaman = 事情发生在你身上。
