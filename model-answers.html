SET 1 · Kebersihan Sekolah

推荐安全路线

Pengalaman: persediaan → pembahagian tugas → membersihkan kawasan → peristiwa utama → hasil → perasaan.

Fakta: membuang sampah dengan betul; jadual bertugas; kempen kebersihan.

Laporan: tajuk → tarikh/tempat/tujuan → aktiviti → hasil → penutup → penyedia laporan.

范文示例｜Pengalaman Gotong-royong

Pada hari Sabtu yang lalu, sekolah saya telah mengadakan Program Gotong-royong Perdana. Saya dan rakan-rakan tiba di sekolah pada awal pagi kerana ingin membantu membersihkan kawasan sekolah.

Sebelum aktiviti bermula, guru penasihat memberikan taklimat ringkas dan membahagikan kami kepada beberapa kumpulan. Kumpulan saya ditugaskan membersihkan taman serta longkang berhampiran kantin.

Kami bekerjasama menyapu daun kering, mengutip sampah dan membersihkan longkang. Ketika sedang bekerja, kami mendapati saluran air tersumbat oleh daun dan sampah. Dengan bantuan guru, kami berjaya membersihkannya sehingga air dapat mengalir dengan lancar.

Selepas beberapa jam, kawasan sekolah kelihatan lebih bersih dan ceria. Walaupun berasa penat, kami berpuas hati melihat hasil usaha bersama.

Saya berasa gembira kerana dapat menyumbang kepada kebersihan sekolah. Pengalaman tersebut mengajar saya tentang kepentingan kerjasama dan tanggungjawab. Saya berharap program seperti ini dapat diadakan lagi pada masa hadapan.

SET 2 · Gaya Hidup Sihat

Pengalaman: aktiviti kecergasan / kempen kesihatan.

Pendapat: pemakanan seimbang; bersenam; tidur dan rehat mencukupi.

Syarahan: sapaan → pengenalan tajuk → 3 isi → seruan → penutup.

SET 3 · Teknologi

Pengalaman: penggunaan teknologi dalam pembelajaran.

Fakta: mencari maklumat; komunikasi; pembelajaran lebih mudah, dengan penggunaan secara berhemah.

Surat: kenal pasti penerima dahulu, kemudian pilih rasmi atau tidak rasmi dan masukkan isi yang menjawab soalan.

SET 4 · Sukan

Pengalaman: Hari Sukan / pertandingan.

Fakta: kesihatan; disiplin; kerjasama; mengurangkan tekanan.

Laporan: fokus pada program sebenar, urutan aktiviti dan hasil.

SET 5 · Alam Sekitar

Pengalaman: kempen kitar semula / penanaman pokok.

Fakta: amalan 3R; mengurangkan plastik; menjaga kebersihan; menjimatkan sumber.

Rencana/Ucapan: format berubah, tetapi isi mesti kekal menjawab kehendak.

SET 6 · Perpaduan

Pengalaman: sambutan / aktiviti bersama murid pelbagai kaum.

Pendapat: menghormati budaya; bekerjasama; berkomunikasi; menyertai aktiviti bersama.

Berformat: gunakan format yang dinyatakan dalam soalan, bukan format yang paling disukai.
