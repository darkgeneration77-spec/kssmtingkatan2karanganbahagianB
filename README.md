# KSSM Tingkatan 2 Bahasa Melayu — Karangan Bahagian B

Repositori ini membina sistem pembelajaran Karangan Bahagian B Tingkatan 2 berasaskan aliran kerja yang konsisten:

**Tema → Kata Tugas → Jenis / Format → Kehendak Soalan → Perancangan → Penulisan → Semakan → Diagnosis → Pembetulan**

## Prinsip utama

1. Kenal pasti **Tema**.
2. Kenal pasti **Kata Tugas** dan **Kehendak Soalan**.
3. Tentukan **Jenis / Format** yang sesuai.
4. Rancang isi mengikut arah soalan.
5. Bina perenggan secara terancang.
6. Tulis pendahuluan, isi dan penutup yang gramatis serta relevan.
7. Semak bahasa, organisasi dan format.
8. Gunakan diagnosis pengajaran untuk mengenal pasti kelemahan dan membuat pembetulan.

## Struktur perenggan fakta / pendapat

Selaras dengan fokus DSKP Tingkatan 2, latihan utama menggunakan:

**Ayat Topik → Ayat Huraian → Ayat Contoh → Ayat Penegas**

`Kesan` boleh digunakan sebagai jambatan pengembangan apabila sesuai dengan isi dan kehendak soalan, tetapi bukan syarat tetap bagi setiap perenggan.

## Penulisan pengalaman / cerita

Penulisan naratif tidak dipaksa mempunyai konflik besar. Struktur pengajaran yang digunakan ialah:

**Latar → Perkembangan → Detik penting / perubahan / cabaran (jika sesuai) → Tindakan / hasil / penyelesaian → Perasaan / Pengajaran**

## 12 Tema utama

1. Diri & Remaja
2. Keluarga
3. Sekolah & Pendidikan
4. Kesihatan
5. Alam Sekitar
6. Teknologi & Internet
7. Sukan & Rekreasi
8. Keselamatan
9. Masyarakat & Kejiranan
10. Perpaduan
11. Patriotisme
12. Nilai Murni

Tema ialah **bank kandungan**, bukan jawapan tetap. Isi dan ayat topik mesti berubah mengikut `Cara / Langkah`, `Faedah / Kebaikan`, `Kepentingan`, `Punca`, `Kesan`, `Peranan`, `Pendapat / Bincangkan` atau `Pengalaman / Cerita`.

## Penilaian dalam laman ini

Skor empat dimensi — **Kehendak Soalan, Isi & Huraian, Bahasa, Organisasi / Format** — digunakan sebagai **alat diagnosis pengajaran**, bukan sebagai rubrik rasmi KPM dan tidak boleh ditukar terus kepada markah rasmi Bahagian B.
