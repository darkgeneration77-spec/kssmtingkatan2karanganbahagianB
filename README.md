# KSSM Tingkatan 2 Bahasa Melayu — Bahagian B

Repositori untuk membina laman pembelajaran karangan Bahagian B Tingkatan 2.

## Struktur pembelajaran

1. Kenal pasti soalan
2. Cari isi
3. Bina isi: Isi → Huraian → Contoh → Kesan
4. Pendahuluan dan penutup
5. Penanda wacana
6. Tulis sendiri
7. Semak karangan
8. Contoh karangan
9. Latihan pemindahan

## Sasaran

- Bahagian B
- Karangan tidak kurang daripada 180 patah perkataan
- Bimbingan Bahasa Melayu dengan penerangan kata kunci dalam Bahasa Cina
- Disusun mengikut tema

## Tema awal

- Kesihatan
- Alam Sekitar
- Pendidikan
- Keluarga
- Masyarakat
- Keselamatan
- Teknologi
- Amalan Baik
- Pelancongan
- Sukan dan Riadah

Soalan pertama yang akan dijadikan templat standard: **Gaya Hidup Sihat — langkah-langkah penjagaan kesihatan**.
