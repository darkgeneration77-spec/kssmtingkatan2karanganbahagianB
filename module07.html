Module 07｜Ucapan / Syarahan / Ceramah

三者都属于面向听众的写作。格式可以相近，但场合、身份、听众与目的会影响称呼和语气。正文仍必须服从题目的 Kehendak。

先认场合

Ucapan

常见于欢迎、感谢、庆典或正式场合。

Syarahan

围绕某主题有组织地说明或论述。

Ceramah

偏向讲解、教育、提醒或说明某个主题。

共同答题顺序

身份 / 听众 → 场合 → Kata Tugas / Kehendak → Sapaan → Pembuka → Isi → Penutup

例如题目要求 syarahan tentang cara-cara menjaga kesihatan diri，正文就必须写 cara/langkah。若改写成 kepentingan，演讲格式再漂亮也救不了方向。

语言原则

保持面对听众的感觉，但不要每一段机械重复 “Hadirin sekalian”。称呼、开场与结尾应自然配合题目身份和场合；正文内容要有清楚的重点、解释和例子。

快速检查：我是谁？在对谁说？为什么说？题目真正问 Cara、Faedah、Kepentingan 还是其他方向？正文有没有一直回答同一个 Kehendak？
