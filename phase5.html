Phase 5｜Bahagian B 模拟实战

6 套训练题，每套 3 题选 1。重点不是赌题号，而是训练：审题 → 判断 Kehendak → 评估自己最稳的一题 → Planning → 独立写作 → 对照专业范文 → 订正。

说明：这里的“选题评分”只是教学决策工具，不是 KPM 官方评分表，也不代表某个题号固定对应某种文体。

Set 1｜Kebersihan Sekolah

Pengalaman · Langkah · Laporan

Set 2｜Gaya Hidup Sihat

Pengalaman · Faedah · Syarahan Cara

Set 3｜Teknologi

Pengalaman · Kebaikan · Surat Tidak Rasmi

Set 4｜Sukan

Pengalaman · Kepentingan · Laporan

Set 5｜Alam Sekitar

Pengalaman · Langkah · Ucapan Kepentingan

Set 6｜Perpaduan

Pengalaman · Cara Memupuk · Rencana Kepentingan

建议训练顺序

Round 1：只做审题、Kata Tugas、Jenis、3 个 Isi。
Round 2：完整写一篇。
Round 3：用 Checklist 自查。
Round 4：再看专业范文，比较结构与发展，不抄全文。
Round 5：订正后再评估。
