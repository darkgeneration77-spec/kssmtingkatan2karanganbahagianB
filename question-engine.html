Soalan → Engine｜看到题目就知道用什么骨架

考试不会问你“今天想用哪个模板”。先认 Tema → Kata Tugas → Jenis → Kehendak，再选择写作 Engine。

Soalan A

Ceritakan pengalaman anda semasa menyertai aktiviti gotong-royong di sekolah.

Tema: Kebersihan / Sekolah
Kata tugas: Ceritakan
Jenis: Pengalaman
Kehendak: pengalaman semasa gotong-royong

Engine → Setting → Action → Problem → Climax → Resolution → Reflection

进入叙事引擎 →

Soalan B

Huraikan langkah-langkah menjaga kebersihan sekolah.

Tema: Kebersihan / Sekolah
Kata tugas: Huraikan
Jenis: Fakta/Pendapat
Kehendak: langkah, bukan faedah

Engine → Pendahuluan → Ayat Topik → Huraian → Contoh → Kesan → Penegasan → Penutup

进入高分写作引擎 →

Soalan C

Sebagai setiausaha Persatuan Bahasa Melayu, tulis sebuah laporan tentang program yang telah dijalankan.

Kata tugas: tulis sebuah laporan
Jenis: Laporan
Kehendak: program yang telah dijalankan

Engine → Format Laporan + Isi berdasarkan program

进入格式速查 →

Soalan D

Bincangkan faedah penggunaan teknologi dalam pembelajaran.

Tema: Teknologi
Kata tugas: Bincangkan
Jenis: Fakta/Pendapat
Kehendak: faedah teknologi dalam pembelajaran

注意：不要写 langkah menggunakan teknologi。

考场 20 秒判断

① 圈 Kata Tugas　② 写 Tema　③ 标 Jenis　④ 用一句华语说“它到底要我写什么”　⑤ 才决定选不选。
